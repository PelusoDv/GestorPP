Version 2.2.0
► Movimientos ahora devuelve tambien el id
► Los Movimientos ahora son filtrados por usuario:
	■ Solo hay que añadir el nombre de usuario a la URL:
	EJ: /movimientos/todos/Hugo
► Ahora se pueden ordenar los Movimientos segun el criterio enviado en la URL:
	EJ: /movimientos/todos/Hugo?orderby=categoria
	(si no se envia un criterio de orden, por defecto devuelve segun el orden de ids)

Version 2.1.0

► En esta version se modifico completamente la base de datos (ver el DER en el archivo FinTrackDB.png).

► Nuevas Objetos en la base de datos (USURAIO, GRUPO, SUSCRIPCION, PLAN).

► SUSCRIPCIO funciona como tabla intermedia para conectar USUARIOS con un GRUPO y un PLAN determiando.

► Al crear un USUARIO se le asigna una nueva SUSCRIPCION a un PLAN y a un GRUPO:
 	■ Si la suscripcion es a un plan individual, se le asigna uno de los grupos globales 
	("Global" para los usuarios Free,"Premium" para los usuarios Premium).
	■ Si la suscripcion es a un plan grupal, se crea un nuevo GRUPO con un nombre solicitado
	al usuario.

► Al suscribirse a un plan:
	■ Si el PLAN es gratuito, no se añade una fecha de finalizacion hasta que el usuario 
	se suscriba a un nuevo plan. (comming soon)
	■ Si el PLAN NO es gratuito, desde el front hay que sumarle el periodo de tiempo elegido
	por el usuario a la fecha actual de suscripcion. Por ej: 1 mes o 12 meses (Tipo de dato
	manejado por JAVA para la fecha "LocalDate")

► Para registrar un usuario, el body requerido es un DTO del usuario. Ej de JSON:
	{
  	  "usuarioNombre": "pepe",
  	  "nombreCompleto": "Pepe Pérez",
  	  "password": "123456",
 	  "email": "pepe@mail.com",
  	  "plan": "Premium",
  	  "fin": "2025-12-31", // este dato puede ser null para las suscripciones gratuitas
  	  "grupo": "Global"
	}
► Para borrar un usuario, se solicita el el nombre de usuario y contraseña como parametro de URL:
	/usuario/borrar?usuario=pepe&password=123456

► Con un USUARIO y GRUPO creados se pueden generar movimientos como las versiones anteriores con
el nuevo formato del MovimientoDTO. Ej de JSON:
	{
	  "monto": 65000.00,
    	  "descripcion": "cuota facu",
    	  "fecha": "2025-09-05",
    	  "tipo": "Gasto",
   	  "categoria": "Educacion",
  	  "divisa": "Pesos",
   	  "usuario": "pepe",
   	  "grupo": "Global",
		// Campos optativos por si el movimiento es generado via email para almacenar el nombre y correo del emisor
  	  "emisor": null,
  	  "email": null
	}
